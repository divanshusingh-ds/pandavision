**Play a game with just your body movements!** No keyboard, no mouse — just your webcam!

## ✨ Features

- 🎥 **Webcam Control** — Move your body to control the panda
- 🏃 **Touchless Gameplay** — No keyboard or mouse required
- 🦘 **Jump & Duck** — Body up = Jump, Body down = Duck
- ⬅️➡️ **Lane Change** — Lean left/right to change lanes
- 🪙 **Collect Coins** — Grab coins for extra points
- 📈 **High Score** — Beat your own record!
- 🎨 **Beautiful Graphics** — Custom panda art with background

## 🎯 Controls

| Body Movement | Action |
|---------------|--------|
| 👋 Wave Left-Right | Start Game |
| ⬅️ Lean Left | Move Left |
| ➡️ Lean Right | Move Right |
| ⬆️ Body Up | Jump |
| ⬇️ Body Down | Duck |

## 🛠️ Tech Stack

- **Python** 🐍 — Core programming language
- **Pygame** 🎮 — Game engine
- **OpenCV** 📷 — Webcam and computer vision
- **MediaPipe** 👤 — Body tracking (optional)
